## 🛍 HACS là gì?

HACS (Home Assistant Community Store) là hệ thống tiện ích mở rộng cho Home Assistant do cộng đồng phát triển.
HACS cho phép bạn cài đặt trực tiếp từ GitHub các blueprint, tích hợp, bảng điều khiển và thành phần tùy chỉnh của bên thứ ba — kèm thông báo cập nhật và quản lý phiên bản.

### Cách cài đặt HACS

> Trong lần thiết lập đầu tiên, HACS sẽ yêu cầu bạn đăng nhập GitHub và cấp quyền truy cập.  
> Bạn cần có tài khoản GitHub để thực hiện việc này (hãy tạo tài khoản nếu cần: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ Quyền được cấp chỉ là quyền đọc — HACS chỉ có thể tải xuống các kho lưu trữ công khai và không thể sửa đổi tài khoản hoặc dữ liệu GitHub của bạn.  

👉 [Làm theo hướng dẫn thiết lập HACS chính thức](https://hacs.xyz/docs/use/#getting-started-with-hacs)
