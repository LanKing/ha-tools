## 🛍 Czym jest HACS?

HACS (Home Assistant Community Store) to rozwijany przez społeczność system rozszerzeń dla Home Assistant.
Pozwala instalować bezpośrednio z GitHuba zewnętrzne blueprinty, integracje, pulpity i niestandardowe komponenty — z powiadomieniami o aktualizacjach i zarządzaniem wersjami.

### Jak zainstalować HACS

> Podczas pierwszej konfiguracji HACS poprosi o zalogowanie się do GitHuba i autoryzowanie dostępu.  
> Potrzebne jest do tego konto GitHub (w razie potrzeby utwórz je tutaj: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ Autoryzacja zapewnia wyłącznie dostęp do odczytu — HACS może tylko pobierać publiczne repozytoria i nie może modyfikować konta ani danych w GitHubie.  

👉 [Postępuj zgodnie z oficjalną instrukcją konfiguracji HACS](https://hacs.xyz/docs/use/#getting-started-with-hacs)
