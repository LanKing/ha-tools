## 🛍 Šta je HACS?

HACS (Home Assistant Community Store) je sistem proširenja za Home Assistant koji razvija zajednica.
Omogućava instaliranje blueprinta, integracija, nadzornih ploča i prilagođenih komponenti trećih strana direktno s GitHuba — uz obavijesti o ažuriranjima i upravljanje verzijama.

### Kako instalirati HACS

> Tokom prvog podešavanja HACS će zatražiti da se prijavite na GitHub i odobrite pristup.  
> Za to vam je potreban GitHub račun (ako ga nemate, napravite ga ovdje: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ Odobrenje je samo za čitanje — HACS može samo preuzimati javne repozitorije i ne može mijenjati vaš GitHub račun ni podatke.  

👉 [Pratite zvanična uputstva za podešavanje HACS-a](https://hacs.xyz/docs/use/#getting-started-with-hacs)
