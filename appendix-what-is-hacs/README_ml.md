## 🛍 HACS എന്താണ്?

HACS (Home Assistant Community Store) എന്നത് Home Assistant-നായി സമൂഹം വികസിപ്പിക്കുന്ന ഒരു വിപുലീകരണ സംവിധാനമാണ്.
GitHub-ൽ നിന്ന് മൂന്നാം കക്ഷി ബ്ലൂപ്രിന്റുകൾ, ഇന്റഗ്രേഷനുകൾ, ഡാഷ്ബോർഡുകൾ, ഇഷ്ടാനുസൃത ഘടകങ്ങൾ എന്നിവ നേരിട്ട് ഇൻസ്റ്റാൾ ചെയ്യാനും അപ്‌ഡേറ്റ് അറിയിപ്പുകളും പതിപ്പ് മാനേജ്മെന്റും ലഭിക്കാനും ഇത് സഹായിക്കുന്നു.

### HACS എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യാം

> ആദ്യ ക്രമീകരണത്തിനിടെ GitHub-ലേക്ക് സൈൻ ഇൻ ചെയ്ത് ആക്‌സസ് അനുവദിക്കാൻ HACS നിങ്ങളോട് ആവശ്യപ്പെടും.  
> ഇതിനായി ഒരു GitHub അക്കൗണ്ട് ആവശ്യമാണ് (ആവശ്യമെങ്കിൽ ഇവിടെ സൃഷ്ടിക്കുക: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ അനുമതി വായനയ്ക്ക് മാത്രമാണ് — HACS-ന് പൊതു റിപ്പോസിറ്ററികൾ ഡൗൺലോഡ് ചെയ്യാനേ കഴിയൂ; നിങ്ങളുടെ GitHub അക്കൗണ്ടിലോ ഡാറ്റയിലോ മാറ്റം വരുത്താനാകില്ല.
