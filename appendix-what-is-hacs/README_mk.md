## 🛍 Што е HACS?

HACS (Home Assistant Community Store) е систем за проширувања на Home Assistant што го развива заедницата.
Овозможува директно од GitHub да инсталирате blueprint-и, интеграции, контролни табли и приспособени компоненти од трети страни — со известувања за ажурирања и управување со верзии.

### Како да го инсталирате HACS

> При првичното поставување, HACS ќе побара да се најавите на GitHub и да одобрите пристап.  
> За тоа ви е потребна GitHub сметка (создајте ја ако е потребно: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ Овластувањето е само за читање — HACS може само да презема јавни складишта и не може да ја менува вашата GitHub сметка или податоци.  

👉 [Следете ги официјалните упатства за поставување на HACS](https://hacs.xyz/docs/use/#getting-started-with-hacs)
