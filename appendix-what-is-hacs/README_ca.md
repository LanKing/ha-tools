## 🛍 Què és HACS?

HACS (Home Assistant Community Store) és un sistema d’extensions per a Home Assistant gestionat per la comunitat.
Permet instal·lar plànols, integracions, taulers i components personalitzats de tercers directament des de GitHub, amb notificacions d’actualitzacions i gestió de versions.

### Com instal·lar HACS

> Durant la configuració inicial, HACS et demanarà que iniciïs la sessió a GitHub i autoritzis l’accés.  
> Per fer-ho necessites un compte de GitHub (crea’n un si cal: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ L’autorització és només de lectura: HACS només pot descarregar repositoris públics i no pot modificar el teu compte ni les teves dades de GitHub.  

👉 [Segueix les instruccions oficials de configuració de HACS](https://hacs.xyz/docs/use/#getting-started-with-hacs)
