## 🛍 HACS என்றால் என்ன?

HACS (Home Assistant Community Store) என்பது Home Assistant-க்காக சமூகத்தால் உருவாக்கப்படும் ஒரு நீட்டிப்பு அமைப்பாகும்.
GitHub-இலிருந்து மூன்றாம் தரப்பு blueprint-கள், ஒருங்கிணைப்புகள், முகப்புப் பலகைகள் மற்றும் தனிப்பயன் கூறுகளை நேரடியாக நிறுவவும், புதுப்பிப்பு அறிவிப்புகள் மற்றும் பதிப்பு மேலாண்மையைப் பெறவும் இது உதவுகிறது.

### HACS-ஐ நிறுவுவது எப்படி

> முதல் அமைப்பின்போது GitHub-இல் உள்நுழைந்து அணுகலை அங்கீகரிக்க HACS உங்களிடம் கேட்கும்.  
> இதற்கு GitHub கணக்கு தேவை (தேவையானால் இங்கே உருவாக்கவும்: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ அங்கீகாரம் வாசிப்பதற்கே உரியது — HACS பொது களஞ்சியங்களை மட்டுமே பதிவிறக்க முடியும்; உங்கள் GitHub கணக்கையோ தரவையோ மாற்ற முடியாது.
