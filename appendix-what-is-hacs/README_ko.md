## 🛍 HACS란?

HACS(Home Assistant Community Store)는 커뮤니티가 개발하는 Home Assistant용 확장 시스템입니다.
GitHub에서 타사 블루프린트, 통합, 대시보드 및 사용자 지정 구성요소를 직접 설치할 수 있으며 업데이트 알림과 버전 관리도 제공합니다.

### HACS 설치 방법

> 처음 설정할 때 HACS는 GitHub에 로그인하고 접근 권한을 승인하도록 요청합니다.  
> 이를 위해 GitHub 계정이 필요합니다(필요한 경우 여기에서 만드세요: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ 승인은 읽기 전용입니다. HACS는 공개 저장소만 다운로드할 수 있으며 GitHub 계정이나 데이터를 수정할 수 없습니다.  

👉 [HACS 공식 설정 안내를 따르세요](https://hacs.xyz/docs/use/#getting-started-with-hacs)
