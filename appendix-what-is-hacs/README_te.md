## 🛍 HACS అంటే ఏమిటి?

HACS (Home Assistant Community Store) అనేది Home Assistant కోసం సముదాయం అభివృద్ధి చేసే విస్తరణ వ్యవస్థ.
ఇది GitHub నుండి మూడవ పక్ష blueprintలు, ఇంటిగ్రేషన్‌లు, డ్యాష్‌బోర్డ్‌లు మరియు అనుకూల భాగాలను నేరుగా ఇన్‌స్టాల్ చేయడానికి అనుమతిస్తుంది — అప్‌డేట్ నోటిఫికేషన్‌లు మరియు వెర్షన్ నిర్వహణతో.

### HACS‌ను ఎలా ఇన్‌స్టాల్ చేయాలి

> మొదటి సెటప్ సమయంలో GitHubలో సైన్ ఇన్ చేసి యాక్సెస్‌ను అనుమతించమని HACS అడుగుతుంది.  
> దీనికి GitHub ఖాతా అవసరం (అవసరమైతే ఇక్కడ సృష్టించండి: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ అనుమతి చదవడానికి మాత్రమే — HACS పబ్లిక్ రిపోజిటరీలను మాత్రమే డౌన్‌లోడ్ చేయగలదు; మీ GitHub ఖాతా లేదా డేటాను మార్చలేదు.
