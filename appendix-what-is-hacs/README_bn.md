## 🛍 HACS কী?

HACS (Home Assistant Community Store) হলো Home Assistant-এর জন্য কমিউনিটি-পরিচালিত একটি এক্সটেনশন ব্যবস্থা।
এর মাধ্যমে আপনি GitHub থেকে সরাসরি তৃতীয়-পক্ষের ব্লুপ্রিন্ট, ইন্টিগ্রেশন, ড্যাশবোর্ড এবং কাস্টম কম্পোনেন্ট ইনস্টল করতে পারেন—সঙ্গে পাবেন আপডেটের বিজ্ঞপ্তি ও সংস্করণ ব্যবস্থাপনা।

### HACS কীভাবে ইনস্টল করবেন

> প্রথমবার সেটআপের সময় HACS আপনাকে GitHub-এ সাইন ইন করে প্রবেশাধিকার অনুমোদন করতে বলবে।  
> এর জন্য আপনার একটি GitHub অ্যাকাউন্ট প্রয়োজন (প্রয়োজনে এখানে তৈরি করুন: [https://github.com/signup](https://github.com/signup))।  
> 🧘‍♂️ অনুমোদনটি শুধু-পঠনযোগ্য—HACS কেবল পাবলিক রিপোজিটরি ডাউনলোড করতে পারে এবং আপনার GitHub অ্যাকাউন্ট বা ডেটা পরিবর্তন করতে পারে না।
