## 🛍 什麼是 HACS？

HACS（Home Assistant Community Store）是一套由社群推動的 Home Assistant 擴充系統。
它可讓你直接從 GitHub 安裝第三方藍圖、整合、儀表板及自訂元件，並提供更新通知與版本管理。

### 如何安裝 HACS

> 首次設定時，HACS 會要求你登入 GitHub 並授權存取。  
> 你需要一個 GitHub 帳號（如有需要，可在此建立：[https://github.com/signup](https://github.com/signup)）。  
> 🧘‍♂️ 此授權僅限讀取 — HACS 只能下載公開儲存庫，無法修改你的 GitHub 帳號或資料。  

👉 [依照 HACS 官方設定說明操作](https://hacs.xyz/docs/use/#getting-started-with-hacs)
