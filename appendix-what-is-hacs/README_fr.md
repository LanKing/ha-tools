## 🛍 Qu’est-ce que HACS ?

HACS (Home Assistant Community Store) est un système d’extensions pour Home Assistant développé par la communauté.
Il permet d’installer directement depuis GitHub des blueprints, intégrations, tableaux de bord et composants personnalisés tiers, avec notifications de mise à jour et gestion des versions.

### Comment installer HACS

> Lors de la configuration initiale, HACS vous demandera de vous connecter à GitHub et d’autoriser l’accès.  
> Vous devez disposer d’un compte GitHub (créez-en un si nécessaire : [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ L’autorisation est en lecture seule — HACS peut uniquement télécharger des dépôts publics et ne peut pas modifier votre compte ou vos données GitHub.  

👉 [Suivez les instructions officielles de configuration de HACS](https://hacs.xyz/docs/use/#getting-started-with-hacs)
