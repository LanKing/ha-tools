## 🛍 Какво е HACS?

HACS (Home Assistant Community Store) е управлявана от общността система за разширения на Home Assistant.
Тя ви позволява да инсталирате чертежи, интеграции, табла и персонализирани компоненти от трети страни директно от GitHub — с известия за актуализации и управление на версиите.

### Как да инсталирате HACS

> При първоначалната настройка HACS ще ви помоли да влезете в GitHub и да разрешите достъп.  
> За това ви е необходим GitHub акаунт (създайте такъв при нужда: [https://github.com/signup](https://github.com/signup)).  
> 🧘‍♂️ Разрешението е само за четене — HACS може единствено да изтегля публични хранилища и не може да променя вашия GitHub акаунт или данни.  

👉 [Следвайте официалните инструкции за настройване на HACS](https://hacs.xyz/docs/use/#getting-started-with-hacs)
