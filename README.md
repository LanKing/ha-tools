# 🏠 Home Assistant Tools
_My different atomic solutions for Home Assistant_

- 🚫 [MDI Off Fallback for Home Assistant](https://github.com/LanKing/ha-mdi-off-fallback) - _Home Assistant lets you use any MDI icon, but not every icon has an -off variant. As a result, a device may already be off while its icon still looks active. This plugin automatically adds an MDI-style slash to inactive entities when no native off icon is available._

- ⏲️ [Z2M Knob — Gesture Action Controller (Moes ZG-101ZD & similar AliExpress-sold knobs)](https://github.com/LanKing/z2m-knobs-gesture-controller) - _Assign actions to gestures of your Zigbee2MQTT rotary knob in Home Assistant — with false-event filtering and support for Moes and similar AliExpress rotary knobs._

- 🌫️ [Air purifier dashboard lovelace card with pm2.5 and other features](air-purifier/dashboard-card/README.md)
